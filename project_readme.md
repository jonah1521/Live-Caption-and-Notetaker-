# Live Caption & Note Taker

An accessible web application designed for deaf and hard-of-hearing students to follow live speech with real-time captions and take class notes side-by-side.

## Features
- Real-time speech-to-text using the browser Web Speech API
- Side-by-side view for live captions and personal notes
- Quick button to copy captions into notes
- Mobile and desktop responsive design

## How to Run
Open `index.html` in a Web Speech API-supported browser such as Google Chrome or Microsoft Edge.
